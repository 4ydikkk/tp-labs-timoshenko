1. Чем ветка отличается от копии папки с проектом?
Копия папки — это два независимых набора файлов на диске, 
которые нужно синхронизировать вручную. Ветка в Git — это просто указатель на определённый коммит. 

2. Что произойдёт с историей, если удалить папку проекта, но сохранить .git?
Ничего не потеряется. Папка .git — это и есть сердце репозитория, 
где хранится вся история коммитов, ветки и настройки. Если удалить все рабочие файлы, 
но оставить .git, вы сможете восстановить любой файл или всю папку в том виде,
в котором они были на момент последнего коммита.

3. Зачем нужен Pull Request, если можно коммитить сразу в main?
Pull Request (PR) нужен для безопасности и командной работы.
Он позволяет проверить код перед тем, как он попадёт в основную ветку.
